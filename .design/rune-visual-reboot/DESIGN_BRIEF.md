# Rune Drift Survivors — 황혼의 룬 야전

Status: implementation  
Target: mobile-first 5-minute survivors run  
Primary viewport: 390 × 844 portrait  
Supported verification: 360 × 740, 430 × 932, 740 × 360, 1440 × 900

## Player fantasy

죽어가는 숲의 균열을 따라 이동하며 룬을 각인하고, 몰려드는 괴물을 밀어내는 방랑 룬술사.

## Problem

현재 전장은 어두운 로우폴리 판타지, HUD는 밝은 캐주얼 보드게임, 업그레이드는 수집형 카드게임 문법을 사용한다. 각 화면은 기능하지만 동일한 게임의 시각 언어로 느껴지지 않고, 중복 CSS 오버라이드 때문에 작은 수정도 여러 파일을 추적해야 한다.

## Direction

하나의 시각 언어만 사용한다: **dark rune field**.

- Surface: 차가운 숯빛 돌과 먹색 금속
- Player/growth: 청록 룬광
- Reward/progress: 절제된 호박빛
- Danger/damage: 산호빛 적색
- Text: 따뜻한 양피지색
- Shape: 얇은 절삭선, 6–10px 모서리, 장식보다 실루엣
- Type: 한국어가 주 정보, 영어는 작은 분류 라벨
- Motion: 100–180ms 상태 전환, 보상/피격만 강한 펄스

## Scope

- CSS 전체 교체: 기존 5개 스타일 파일 삭제 후 새 토큰/셸/HUD/오버레이/반응형 파일 생성
- HUD, 보스 상태, 튜토리얼, 터치 컨트롤 마크업 재구성
- 업그레이드 선택을 수집형 카드에서 룬 석판으로 재구성
- 로딩, 일시정지, 결과 화면을 동일한 룬 석판 언어로 재구성
- 캔버스 배경·안개와 공용 아트 토큰을 새 팔레트에 맞춤
- 기존 입력, 전투, 스폰, 성장, 업그레이드 로직 보존

## Non-scope

- 무기 밸런스와 전투 수치 전면 변경
- 3D 모델 교체 또는 신규 모델 제작
- 메타 성장, 상점, 캐릭터 선택
- Rune Circuit 신규 전투 메커니즘

## Acceptance criteria

1. 같은 selector의 기본 스타일이 여러 파일에서 오버라이드되지 않는다.
2. 기존 `casual-ui.css`, `*-core.css`는 남지 않는다.
3. 모바일에서 체력, XP, 남은 시간, 일시정지, 현재 튜토리얼을 확인할 수 있다.
4. 업그레이드 선택은 3초 안에 이름, 효과, 역할을 읽을 수 있다.
5. 위험, 성장, 보상은 색뿐 아니라 라벨과 형태로 구분된다.
6. 모든 기존 QA 흐름과 실제 키보드/터치 입력이 동작한다.
7. 지원 뷰포트에서 핵심 UI가 화면 밖으로 나가거나 전투 중심을 가리지 않는다.
