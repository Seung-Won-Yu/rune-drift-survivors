# 잿빛의 숲 플레이·개발 안내

`/survivor/`는 Canvas2D로 만든 5분 서바이버 첫 챕터다. 기존 Three.js 게임은 `/`에 남아 있다.

## 플레이

1. 동료를 고르고 숲에 들어간다. WASD/방향키 또는 터치 스틱으로 이동한다. 공격은 자동이다.
2. 파란 경험치를 모아 성장 카드를 고른다. 카드 선택 중에는 전투가 멈춘다. 클릭/터치, 숫자 1–3, Tab과 Enter를 사용할 수 있다.
3. 정예의 원형 공격 예고를 피하고 처치한다. 준비된 무기는 다음 성장에서 진화할 수 있다.
4. 1:15, 2:30, 3:45에 생기는 열매는 가까이 가면 체력 25를 회복한다. 가득 찬 체력에서는 소모하지 않으며 80초 뒤 사라진다.
5. 4:00에 재의 군주가 나타난다. 돌진선 옆으로 피하고 가시 사이를 통과한다. 군주를 쓰러뜨리면 승리, 5분까지 남아 있으면 생존으로 기록한다.

Escape/P 또는 HUD 버튼으로 일시정지한다. 소리 버튼으로 음향을 끄고 켠다. 페이지를 떠나면 전투가 멈춘다. 장치의 모션 감소 설정을 반영한다.

| 동료 | 특성 | 해금 |
| --- | --- | --- |
| 잿빛 검사 | 황동 검, 체력 100 | 처음부터 |
| 불씨술사 | 추적 불씨, 체력 85, 빠른 이동 | 한 판 60초 생존 |
| 룬 수호자 | 회전 룬 2개, 체력 125, 피해 15% 감소 | 누적 200 처치 |

| 진화 | 조건 | 변화 |
| --- | --- | --- |
| 여명의 검 | 검 3, 룬 1, 정예 1 | 넓은 베기와 관통 검기 |
| 잿불 혜성 | 불씨 3, 발걸음 1, 정예 1 | 적중 폭발, 연소 전문화에서는 지속 피해 강화 |
| 월광 고리 | 룬 3, 심장 1, 정예 1 | 추가 룬과 밀어내는 파동 |

## 숲의 선택 확장

레벨 4 이후 무기를 3단계 이상 키우면 전문화 두 갈래를 제시한다. 한 무기에서는 한 갈래만 선택한다. 일반 강화를 먼저 고르고 전문화를 나중에 선택할 수도 있다. 기존 진화는 전문화와 함께 작동한다.

| 무기 | 첫 갈래 | 두 번째 갈래 |
| --- | --- | --- |
| 검 | 반월 검법: 넓은 각도·범위, 피해 감소 | 일점 검법: 좁은 각도, 강한 피해·느린 재사용 |
| 불씨 | 번지는 불꽃: 지속 피해, 처치 시 불붙지 않은 두 적에게 전파 | 응축 화염: 느린 발사, 넓은 폭발 |
| 룬 | 수호 결계: 근거리 밀어내기·받은 피해 감소 | 별자리 궤도: 먼 회전 반경·높은 피해 |

- **봉인 제단:** 0:45에 등장한다. 원 안에서 누적 10초를 버티면 유물을 얻는다. 원 밖에서는 진행이 멈추고 재진입하면 이어진다.
- **저주 상자:** 2:15에 등장한다. 가까이 가서 살펴본 뒤 수락 또는 거절한다. 수락하면 18초 동안 일반 적의 이동 속도·접촉 피해가 25% 증가하고, 살아남으면 유물을 얻는다. 확인 화면에서 Escape/P는 거절이다.
- 미완료 제단과 수락하지 않은 상자는 3:45에 사라진다. 이미 수락한 저주는 약속한 시간이 끝날 때까지 유지한다. 이벤트를 무시해도 보스와 승패는 그대로 진행한다.
- 보상은 중복 없는 유물 3개 중 하나다. 꺼지지 않는 숯(점화), 왕을 노리는 송곳니(검의 정예 특화), 서리 종(룬의 둔화), 바람 돛(이동 중 불씨 연사), 이슬 씨앗(경험치 회복), 가시 심장(피격 반격)이 있다. 해당 무기가 없는 유물은 그 무기를 얻어야 발동한다.
- 일시정지와 결과에서 현재 전문화·유물 효과를 확인한다. 발견한 종류와 최근 판의 선택은 저장하지만 새 판에 효과가 이월되지는 않는다.

대기 화면의 여정 기록에서 최근 5판과 동료별 기록을 확인한다. 저장소가 차단되면 현재 창 안에서는 기록과 해금이 유지되지만 닫은 뒤에는 사라질 수 있다. 기록은 다른 브라우저나 기기로 동기화하지 않는다.

## 개발과 검사

Node.js 22와 npm을 사용한다.

```sh
npm ci
npm run dev
npm run qa:survivor
node scripts/survivor-balance.mjs
node scripts/survivor-expansion-balance.mjs
```

로컬 브라우저 검사는 설치된 Chrome을 헤드리스로 사용한다. Chromium을 설치해 CI 모드로도 실행할 수 있다.

```sh
npx playwright install chromium
CI=true npm run qa:survivor
```

GPU 없이 최대 부하 렌더링을 재현하려면 다음 명령을 사용한다. 게임 시간·개체 상한·프레임 기준을 그대로 검사한다.

```sh
ASH_QA_SOFTWARE=1 npx playwright test --config scripts/playwright-survivor.config.mjs --grep 'late-game entity caps'
```

전체 시간 검사에는 개발 서버가 필요하다. 검사 중에는 해당 서버의 소스를 변경하지 않는다. 각 동료를 별도 브라우저에서 실행해 약 5분 걸리며 결과와 프레임 수치를 `output/playwright/survivor/fullrun/`에 저장한다.

```sh
npm run qa:survivor:fullrun
```

`ASH_FULLRUN_URL`로 별도 서버 URL을 지정할 수 있다. 자동 입력은 정상 이동·성장/유물 선택·상자 수락만 수행하며 개발 모드에만 존재한다. 인위적으로 적 체력을 높이는 `stress`/`stress-expansion` 장면은 렌더링 부하 검사에서만 사용한다.

배포와 같은 하위 경로는 다음 명령으로 확인한다. production 검사 스크립트는 preview 서버를 자체 실행하고 종료한다.

```sh
GITHUB_PAGES=true npm run build
npm run qa:survivor:production
```

`npm run qa:smoke`는 기존 3D 게임의 86개 검사다. main 배포 workflow는 두 게임의 검사와 새 게임의 production 검사를 실행한 뒤 Pages에 배포한다.

확장 코어 검사는 57개, 브라우저 검사는 40개다. 확장 경로 진단은 6개 경로 × 3개 시드의 18판을 실행한다.

구조와 실제 검증 범위는 [통합 기록](./design/survivor-restart/09-RELEASE.md), 자산 출처와 포즈 한계는 [그림 문서](../public/art/survivor/README.md)를 참고한다.
