# 잿빛의 숲 플레이·개발 안내

`/survivor/`는 Canvas2D로 만든 5분 서바이버 첫 챕터다. 기존 Three.js 게임은 `/`에 남아 있다.

## 플레이

1. 동료와 출발 기념품 하나를 고르고 숲에 들어간다. 로비의 숲의 도감에서 수집 진행도와 다음 발견 조건을 확인한다. WASD/방향키 또는 터치 스틱으로 이동한다. 공격은 자동이다.
2. 파란 경험치를 모아 성장 카드를 고른다. 카드 선택 중에는 전투가 멈춘다. 클릭/터치, 숫자 1–3, Tab과 Enter를 사용할 수 있다.
3. 1·2·3분부터 순서대로 나오는 정예의 내려찍기·돌진선·포자 지대를 피하고 처치한다. 이전 정예가 남아 있으면 다음 정예는 기다린다. 처치 후 6초간 새 일반 적이 줄고 가까운 경험치가 모인다. 준비된 무기는 다음 성장에서 진화할 수 있다.
4. 1:15, 2:30, 3:45에 생기는 열매는 가까이 가면 체력 25를 회복한다. 가득 찬 체력에서는 소모하지 않으며 80초 뒤 사라진다.
5. 4:00에 재의 군주가 나타난다. 돌진선 옆으로 피하고 가시 사이를 통과한다. 군주를 쓰러뜨리면 승리, 5분까지 남아 있으면 생존으로 기록한다.

Escape/P 또는 HUD 버튼으로 일시정지한다. 소리 버튼으로 음향을 끄고 켠다. 페이지를 떠나면 전투가 멈춘다. 장치의 모션 감소 설정을 반영한다.

| 동료 | 특성 | 해금 |
| --- | --- | --- |
| 잿빛 검사 | 황동 검, 체력 100 | 처음부터 |
| 불씨술사 | 추적 불씨, 체력 85, 빠른 이동 | 한 판 60초 생존 |
| 룬 수호자 | 회전 룬 2개, 체력 125, 피해 15% 감소 | 누적 200 처치 |

| 진화 | 조건 | 변화 |
| --- | --- | --- |
| 여명의 검 | 검 3, 룬 1, 정예 1 | 넓은 베기와 관통 검기 |
| 잿불 혜성 | 불씨 3, 발걸음 1, 정예 1 | 적중 폭발, 연소 전문화에서는 지속 피해 강화 |
| 월광 고리 | 룬 3, 심장 1, 정예 1 | 추가 룬과 밀어내는 파동 |

## 동료 고유 능력과 전승

- **잿빛 결의:** 실제 검 적중 6회로 다음 검격을 강화한다(피해 ×1.6, 범위 +25). 한 번의 검격은 최대 3회 충전한다. 빗나간 강화 검격은 결의를 소모하지 않는다. 관통 검기는 충전하지 않는다.
- **잔불 걸음:** 이동 거리 480으로 다음 발사의 첫 불씨를 강화한다(피해 ×1.45, 폭발 반경 +18). 번지는 불꽃은 추가 폭발 대신 근처에 연소를 붙인다. 정지하거나 메뉴를 열어둔 시간에는 충전하지 않는다.
- **숲의 수호:** 회전 룬 적중 6회로 4초 동안 보호막 20을 얻는다. 충전 간격은 최소 0.35초이며 발동 뒤 5초 동안 재충전하지 않는다. 방어 보정 뒤 피해를 흡수하고, 완전히 막은 공격은 체력 피해나 가시 심장 반격으로 취급하지 않는다.

로비의 전투법 전승에서 해당 동료의 시작 무기에 속하는 **이미 발견한 전문화 하나**를 고를 수 있다. 무기 1단계부터 갈래 효과가 적용되며 무기 단계·경험치·진화는 직접 성장시켜야 한다. 자유로운 출발은 기존처럼 전투 중 선택한다. 동료별 선택은 저장되지만 이전 저장에 발견이 있어도 자동으로 전승하지 않는다. 도감의 발견한 전투법에서 ‘전승 준비’를 눌러 해당 동료의 로비로 연결할 수도 있다.

같은 주무기의 수집 목표와 전승이 충돌하면 새로 고른 선택을 우선한다. 결과의 ‘다른 빌드 실험’은 전승을 해제하고 목표만 잡으므로 기존 목표 전용 동작을 유지한다. 다른 무기도 성장으로 얻을 수 있어 다른 무기의 수집 목표는 계속 유효하다.

`node scripts/survivor-progression-balance.mjs`는 세 동료·두 갈래·다섯 시드·다섯 준비 방식의 150판을 진단한다. 자동 입력은 경고가 보인 뒤 0.2초 반응 지연을 두고 실제 이동과 제시된 카드만 선택한다. 승리 수치가 사람의 난이도나 재미를 뜻하지는 않는다.

## 숲의 선택 확장

레벨 4 이후 무기를 3단계 이상 키우면 전문화 두 갈래를 제시한다. 한 무기에서는 한 갈래만 선택한다. 일반 강화를 먼저 고르고 전문화를 나중에 선택할 수도 있다. 기존 진화는 전문화와 함께 작동한다.

하단 장착 무기는 기본·전문화·진화 상태에 맞는 도감 그림과 강화 단계를 표시한다. 이미 고른 무기를 강화할 때도 같은 그림과 선택한 갈래가 이어진다. 진화 공격에는 무기마다 다른 작은 문양을 표시한다. [성장 표현과 검증](./design/survivor-restart/25-GROWTH-VISUAL-IDENTITY.md).

| 무기 | 첫 갈래 | 두 번째 갈래 |
| --- | --- | --- |
| 검 | 반월 검법: 넓은 각도·범위, 피해 감소 | 일점 검법: 좁은 각도, 강한 피해·느린 재사용 |
| 불씨 | 번지는 불꽃: 지속 피해, 처치 시 불붙지 않은 두 적에게 전파 | 응축 화염: 느린 발사, 넓은 폭발 |
| 룬 | 수호 결계: 근거리 밀어내기·받은 피해 감소 | 별자리 궤도: 먼 회전 반경·높은 피해 |

- **봉인 제단:** 0:45에 등장한다. 원 안에서 누적 10초를 버티면 유물을 얻는다. 원 밖에서는 진행이 멈추고 재진입하면 이어진다.
- **저주 상자:** 2:15에 등장한다. 가까이 가서 살펴본 뒤 수락 또는 거절한다. 수락하면 18초 동안 일반 적의 이동 속도·접촉 피해가 25% 증가하고, 살아남으면 유물을 얻는다. 확인 화면에서 Escape/P는 거절이다.
- 미완료 제단과 수락하지 않은 상자는 3:45에 사라진다. 이미 수락한 저주는 약속한 시간이 끝날 때까지 유지한다. 이벤트를 무시해도 보스와 승패는 그대로 진행한다.
- 보상은 중복 없는 유물 3개 중 하나다. 꺼지지 않는 숯(점화), 왕을 노리는 송곳니(검의 정예 특화), 서리 종(룬의 둔화), 바람 돛(이동 중 불씨 연사), 이슬 씨앗(경험치 회복), 가시 심장(피격 반격)이 있다. 해당 무기가 없는 유물은 그 무기를 얻어야 발동한다.
- 일시정지와 결과에서 현재 전문화·유물 효과를 확인한다. 발견한 종류와 최근 판의 선택은 저장한다. 유물 효과는 다음 판으로 이월되지 않으며, 전문화는 출발 준비에서 명시적으로 고른 전승 하나만 적용한다.

대기 화면의 여정 기록에서 최근 5판과 동료별 기록을 확인한다. 저장소가 차단되면 현재 창 안에서는 기록과 해금이 유지되지만 닫은 뒤에는 사라질 수 있다. 기록은 다른 브라우저나 기기로 동기화하지 않는다.

## 개발과 검사

Node.js 22와 npm을 사용한다.

```sh
npm ci
npm run dev
npm run qa:survivor
node scripts/survivor-balance.mjs
node scripts/survivor-expansion-balance.mjs
```

로컬 브라우저 검사는 설치된 Chrome을 헤드리스로 사용한다. Chromium을 설치해 CI 모드로도 실행할 수 있다.

```sh
npx playwright install chromium
CI=true npm run qa:survivor
```

GPU 없이 최대 부하 렌더링을 재현하려면 다음 명령을 사용한다. 게임 시간·개체 상한·프레임 기준을 그대로 검사한다.

```sh
ASH_QA_SOFTWARE=1 npx playwright test --config scripts/playwright-survivor.config.mjs --grep 'late-game entity caps'
```

전체 시간 검사는 필요하면 개발 서버를 실행한다. 검사 중에는 해당 서버의 소스를 변경하지 않는다. CI와 같은 Playwright Chromium이 세 동료의 독립 브라우저와 종료를 관리하며 약 5분 걸린다. 처음에는 `npx playwright install chromium`으로 검사 브라우저를 준비한다. 결과와 프레임 수치를 `output/playwright/survivor/fullrun/`에 저장한다.

```sh
npm run qa:survivor:fullrun
```

`ASH_FULLRUN_URL`로 별도 서버 URL을 지정할 수 있다. 자동 입력은 정상 이동·성장/유물 선택·상자 수락만 수행하며 개발 모드에만 존재한다. 인위적으로 적 체력을 높이는 `stress`/`stress-expansion` 장면은 렌더링 부하 검사에서만 사용한다.

배포와 같은 하위 경로는 다음 명령으로 확인한다. production 검사 스크립트는 preview 서버를 자체 실행하고 종료한다.

```sh
GITHUB_PAGES=true npm run build
npm run qa:survivor:production
```

`npm run qa:smoke`는 기존 3D 게임의 87개 검사다. main 배포 workflow는 두 게임의 검사와 새 게임의 production 검사를 실행한 뒤 Pages에 배포한다.

현재 코어 검사는 137개, 브라우저 검사는 126개다. 실제 시간 전체 플레이 검사는 3개다. 확장 경로 진단은 6개 경로 × 3개 시드의 18판을 실행한다.

구조와 실제 검증 범위는 [통합 기록](./design/survivor-restart/09-RELEASE.md), 자산 출처와 포즈 한계는 [그림 문서](../public/art/survivor/README.md)를 참고한다.


## 숲의 도전과 출발 기념품

로비의 ‘출발 준비’에서 동료·기념품·서약을 고르고, ‘여정 기록’에서 숙련 인장·숲의 도전·최근 여정을 확인한다. 시작 버튼과 선택 요약은 내부 스크롤과 관계없이 화면 아래에 남는다. 도전의 조건·진행도·보상은 기록 탭의 ‘숲의 도전’을 펼쳐 읽는다. 제단을 완료한 여정 종료로 ‘제단의 씨앗’(수집 +28 / 최대 체력 −10), 서로 다른 전문화 2개 기록으로 ‘갈림길의 리본’(이동 +12 / 최대 체력 −10), 군주 격파로 ‘재의 왕관 조각’(최대 체력 +15 / 이동 −8)을 해금한다. 전문화·진화·유물 중 서로 다른 3개를 기록하면 ‘첫빛의 책갈피’(첫 60초 획득 경험치 +20%)가 열린다. 쓰러진 판도 발견·도전 기록에 포함된다.

기념품 선택은 시작 버튼 앞의 출발 준비에 표시한다. 해금된 기념품 하나를 출발 전에 선택한다. 빈손은 기본 능력이며 필수 해금은 없다. 선택은 브라우저에 저장되고 재도전에도 적용되지만 효과가 누적되지는 않는다. 일시정지와 결과에서 현재 기념품의 효과를 확인할 수 있다. 기존 전문화·승리 기록은 인정하며, 과거 제단 완료는 기록이 없어 추정하지 않는다.

기념품별 정상 규칙 진단: `node scripts/survivor-journey-balance.mjs` (동료 3명 × 빈손/기념품 5설정, 시드 42). 실제 플레이 평가는 별도로 필요하다. [제작 및 검증 기록](./design/survivor-restart/11-JOURNEY-FEEL.md).

## 숲의 도감

로비의 도감 버튼에서 동료 3명, 전문화 6개, 진화 3개, 유물 6개, 기념품 4개를 확인한다. 전체와 동료/무기/유물/기념품 분류별 진행도를 보여준다. 무기·유물·기념품은 각각 다른 그림으로 표시하고, 미발견 항목은 그 그림의 실루엣으로 남는다. 미발견 항목도 선택할 수 있으며, 효과·조건·진화 조합을 미리 살펴볼 수 있다.

전문화·진화·유물은 선택 후 여정을 마치면 도감에 기록된다. 도감 열람은 발견을 추가하지 않는다. 동료와 기념품은 기존 해금 조건으로 기록하며, 빈손은 수집 항목에서 제외한다. 기존 `ash-profile-v1`의 발견·해금 기록을 그대로 읽는다.

도감은 한 화면 안에 고정되며 제목·진행도·분류·출발 준비 버튼은 스크롤되지 않는다. PC에서는 목록과 상세 설명을 각각 내부에서 스크롤한다. 설명 영역에 Tab으로 이동한 뒤 방향키·PageDown·End로도 읽을 수 있다. 모바일은 본문만 스크롤하고, 분류는 옆으로 밀어 고른다. 항목을 누르면 설명으로 이동하고, ‘선택 항목으로 돌아가기’로 목록에 복귀한다. Escape/P 또는 ‘출발 준비’로 돌아간다. 로비는 준비와 기록 영역, 결과는 보상 본문만 내부에서 스크롤한다. 로비의 시작 버튼과 결과의 재도전·출발 준비 버튼은 고정된다. 다른 선택 메뉴의 긴 내용도 패널 안에서만 스크롤한다. 도감은 여정을 진행시키지 않는다. [기획·검증 기록](./design/survivor-restart/22-CODEX-AND-PREPARATION.md).

## 숲의 적을 상대하는 방법

- **버섯 정령:** 18초 이후에는 처치한 자리에 포자가 남을 수 있다. 점선 원이 차오르는 0.7초 동안은 안전하며, 이후 1.6초 동안 위험하다. 원을 돌아가거나 사라진 뒤 경험치를 줍는다. 포자는 최대 4개다.
- **숲 사냥개:** 몸을 낮추며 돌진할 길을 고정한다. 0.8초 예고 중 길 옆으로 이동하면 피할 수 있다. 돌진 뒤 0.65초의 빈틈을 노린다.
- **나무 거인:** 팔을 들면 내려찍을 원 밖으로 이동한다. 일반 거인은 1.15초 뒤 반경 62에 공격하고, 정예는 기존의 더 빠르고 넓은 공격을 사용한다. 예고 중 처치하면 공격이 취소된다.

처음 30초는 버섯만, 이후 사냥개, 90초부터 일반 거인이 합류한다. 군주전에서는 일반 거인 비중이 줄어든다. 첫 만남에 대응 안내가 나타나며, 상단에 현재 숲의 국면을 표시한다. 색상뿐 아니라 점선·원·직선과 자세로 예고를 구분하고 움직임 감소 설정에서도 유지한다. [설계와 검증 기록](./design/survivor-restart/12-ENEMY-ROLES.md).

개발 전용 장면: `window.__ASH_QA__.scenario('enemy-spores')`, `'enemy-hound'`, `'enemy-giant'`, `'enemy-warnings'`. `/survivor/?qa`에서만 사용하며 배포 빌드에는 QA 전역이 없다.

## 성장과 회복을 고르기

성장 화면에서 현재 체력을 확인할 수 있다. 체력이 40% 이하이고 회복 선택지가 있으면 해당 카드의 테두리와 ‘회복 선택 가능’ 안내가 표시된다. 카드 순서와 키보드 선택은 그대로이며, 공격 성장과 회복 중 하나를 직접 고른다.

‘숲의 심장’은 최대 체력 증가와 회복 후 체력을 함께 표시하고, ‘생명의 숨결’은 현재 체력 → 회복 후 체력을 표시한다. 예를 들어 95/100에서 생명의 숨결을 고르면 100/100이 된다. [진단과 개선 기록](./design/survivor-restart/13-RECOVERY-CHOICES.md).

## 공격이 맞는 순간

기본 무기부터 적중 지점에 검은 날카로운 황금 섬광, 불씨는 주황 원형 충격, 룬은 민트색 마름모를 표시한다. 맞은 일반 적은 잠깐 눌렸다 복원되고, 직접 공격으로 처치하면 마지막 적중 방향으로 튕기며 사라진다. 공격을 예고하는 적의 자세는 유지한다.

검의 접촉음·불의 폭발음·룬의 낮은 충격음을 구분한다. 플레이어 피격을 제외한 중요한 알림과 타격이 겹치면 둘을 함께 재생하되, 군중의 모든 적중음을 중첩하지 않는다. 움직임 감소 설정에서는 움찔·처치 이동·파편을 줄이고 적중 표시는 유지한다. [설계와 검증](./design/survivor-restart/14-IMPACT-FEEL.md).

개발 장면은 `/survivor/?qa`의 `window.__ASH_QA__.scenario('impact-sword')`, `'impact-ember'`, `'impact-orbit'`다. 정상 적중으로 체력을 깎는 장면이며 배포에서는 QA 기능이 제거된다.

검은 준비·접촉·후속 동작·복귀의 네 구간으로 표현하고, 세 동료는 서로 다른 자세와 무게로 시전한다. 무기를 진화시키면 1.35초간 작은 파편과 무기 이름이 표시된다. 이 연출은 전투 시간에 맞춰 멈추고 재도전에서 초기화되며, 움직임 감소에서는 고정 표시만 남는다. 진화한 무기는 추가 접촉 문양과 음색으로 구분한다. 정예를 쓰러뜨리면 짧은 ‘정예 격파’ 표시와 마무리음이 나오며, 기존 회복·경험치 보상은 유지된다. [공격 동작과 처치 연출 기록](./design/survivor-restart/15-ATTACK-WEIGHT.md).

## 플레이어 피격 구분

실제 체력이 줄어들면 공격이 온 방향에 짧은 접촉 표식을 표시하고 몸이 반대쪽으로 반동을 보인다. 체력 표시 위에는 실제 잃은 체력과 원인이 약 0.95초간 나타나며, 체력바의 밝은 잔상이 손실량을 보여준다. 무적 중에는 캐릭터를 반복해서 깜빡이지 않고 발밑 보호 표시를 유지한다. 피격음 직후 0.18초 동안 일반 적중음·수집음을 억제해 공격과 피격을 구분한다. 움직임 감소에서는 반동과 체력바 잔상 이동을 끄며, 피해량·원인·방향은 남긴다. [조사와 검증](./design/survivor-restart/16-PLAYER-DAMAGE-FEEDBACK.md).

## 전투 리듬

공세 사이에는 일반 적의 증원이 줄어드는 정리 시간이 있습니다. 기존 적과 공격은 그대로 남으므로 경험치를 모으면서 위험을 피하세요. 무기 진화 직후에는 8초간 증원이 줄고, 타이머 위에 남은 시간이 표시됩니다. 정예와 4분 보스 등장은 예정대로 진행됩니다. [설계·비교 진단](./design/survivor-restart/17-COMBAT-PACING.md).

## 숲의 사건과 보상 미리보기

발견한 사건의 ‘보상 후보 살펴보기’를 누르면 전투가 멈추고 조건과 실제 유물 후보 3개가 표시됩니다. 돌아가기 또는 Esc/P로 전투를 재개합니다. 저주 상자는 접근 후 수락 화면에서 후보를 확인할 수 있습니다. 완료 후에도 같은 후보 중 하나를 고릅니다. 카드의 ‘무기 필요’는 해당 무기를 얻은 뒤 효과가 적용된다는 뜻입니다. 두 사건은 서로 다른 후보를 제시합니다. [설계와 조사](./design/survivor-restart/18-RISK-REWARD-CHOICES.md).


## 다음 판의 빌드 실험

결과는 이번 판에 처음 발견한 전문화·진화·유물만 그림과 함께 표시합니다. ‘도감에서 새 발견 보기’는 실제 새 항목을 열고 키보드 포커스도 그 항목으로 이동합니다. ‘이 빌드로 다음 판 준비’를 누르면 같은 동료의 다른 전문화를 목표로 준비합니다. 동료 선택 화면에서 효과와 조건을 확인하고 출발하세요. 목표는 저장되며 실제 후보가 나타날 때 표시됩니다. 목표를 지우거나 다른 갈래를 골라도 괜찮습니다. 무기는 1단계부터 시작하고 전문화·진화·유물은 새 판에서 다시 얻습니다. [설계와 검증](./design/survivor-restart/19-REPLAY-EXPERIMENTS.md).

## 전투 가독성과 움직임

캐릭터를 적과 아군 공격 효과 위에 그려 밀집 전투에서도 위치를 찾을 수 있게 했다. 모든 적 위험 예고선은 캐릭터보다 위에 남으며, 옅은 범위 채움은 바닥에 그린다. 주변 적이 12마리 이상일 때는 가까운 피해 숫자 8개를 표시하고 먼 적의 불꽃 장식을 줄인다. 실제 피해와 위험 판정은 그대로다.

동료는 프레임의 불투명한 발 위치를 맞추고 실제 이동 거리에 맞춰 발걸음을 바꾼다. 검사의 기본 보폭, 술사의 가벼운 보폭, 수호자의 묵직한 보폭을 구분한다. 버섯의 작은 뛰기·사냥개의 낮은 질주·거인의 무거운 흔들림을 더하고 돌진/내려찍기의 준비와 복귀를 점진적으로 표현한다. 정지할 때는 동료별 작은 호흡 동작을 더한다. 공격·피격 자세가 우선하며 일시정지하면 호흡도 멈춘다. 모션 감소 설정에서는 추가 움직임이 없다. [변경과 검사 근거](./design/survivor-restart/21-COMBAT-READABILITY-MOTION.md).


## 수집 목표·다시 뽑기·동료 숙련·서약

도감에서 미발견 전문화·진화·유물 하나를 이번 판의 목표로 지정한다. 출발 준비, 전투 중 조건 안내, 관련 성장·유물 카드와 결과에 목표가 표시된다. 실제 획득 후 여정 종료로 기록되며, 실패한 목표는 다음 출발에 남는다. 달성한 목표는 자동으로 지워진다. 기존 ‘다음 판의 빌드 실험’과 도감 목표는 하나만 선택한다.

성장 선택 화면에서 기본 1회 다시 뽑을 수 있다. 준비된 진화 후보는 유지하고, 실제로 새 후보를 제시할 수 있을 때만 횟수를 사용한다. 선택 전까지 전투 시간은 멈춘다. 다시 뽑기는 체력·경험치·단계를 주지 않는다.

동료별로 시작 무기의 두 전문화 기록, 시작 무기 진화, 군주 격파의 인장 3개를 모은다. 그 동료의 숙련 완료 후부터 매 판 다시 뽑기가 2회다. 기본 공격력 보너스는 없다. 이전 기록은 동료별 승리와 최근 여정에서 확인되는 빌드만 인정하며, 전체 발견 목록으로 동료별 성과를 추정하지 않는다.

첫 군주 격파 후 ‘짙은 안개’를 선택할 수 있다. 적 체력·받는 피해·획득 경험치가 각각 15% 늘어나며 기본 여정은 그대로 선택 가능하다. 예고 시간과 5분 길이는 같다. 경험치 보너스는 첫빛의 책갈피와 합산해 첫 60초 +35%, 이후 +15%다. 이슬 씨앗의 회복 충전량은 기본 경험치로 계산한다. 도전 난이도 격파 횟수는 동료별로 남는다.

`npm run qa:survivor:progression`은 실제 규칙 120판 진단과 PC·모바일·가로 화면의 실제 시간 챕터 3판을 실행한다. [설계·벤치마크·검증 기록](./design/survivor-restart/23-COLLECTION-MASTERY-AND-VOWS.md).


## 로비와 수집의 시각 완성도

전용 야영지 배경과 동료 모습, 출발 준비/여정 기록 탭, 고정 출발 요약으로 한 화면에서 다음 여정을 준비한다. 일러스트 무대와 한글 명조 제목, 종이 준비 영역으로 세계와 선택을 나눈다. 모바일에서도 작은 동료 무대를 유지하고 내용만 내부에서 스크롤한다. 숲의 도감·성장·유물 선택·기념품·새 발견 결과에는 같은 항목 그림을 사용한다. 열람만으로 발견이나 능력을 주지 않으며 기존 저장 기록과 전투 규칙을 유지한다. [최신 화면·자산·검증 기록](./design/survivor-restart/26-ILLUSTRATED-SANCTUARY.md).


## 동료 중심 출발 화면

동료 선택은 숲 무대에, 전투법·기념품은 오른쪽 준비 장부에 모았다. 새 전신 일러스트는 로비에서만 사용하며 기존 전투 애니메이션은 유지한다. 고유 능력의 행동 요약을 먼저 보여 주고 정확한 수치는 ‘동료의 전투 방식’에서 확인한다. 작은 화면에서도 동료 선택과 출발 버튼이 남으며 내용만 내부 스크롤한다. 전투에는 발밑 리듬, 적중선, 베기 리본과 챔피언 문장을 더했다. [화면·자산·검증 기록](./design/survivor-restart/28-COMPANION-PRESENTATION.md).
