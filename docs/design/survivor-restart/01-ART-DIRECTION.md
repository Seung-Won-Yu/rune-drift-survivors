# 새 뱀서라이크 — 01. 미술 방향과 화면 기준

작성·자료 확인: 2026-09-08
상태: 방향 비교 초안. 2026-09-08 후속 대화에서 캐릭터와 움직임을 중시해 카툰을 우선 후보로 두고, 동일 캐릭터의 도트·카툰 이동/공격 시안 비교를 진행하기로 했다. 최종 스타일은 아직 미정이며 아래 수치는 제작 검증용 제안이다.

## 이번 문서가 정하는 것

새 게임은 이동·자동 공격·처치·경험치 수집·성장의 경험을 중심에 둔다. 전투 화면에서 이 흐름이 보이도록 캐릭터, 적, 배경, 효과, HUD를 함께 설계한다.

기존 게임의 봉인 탐색, 세계관, 미술 자산, 카메라를 새 버전의 필수 조건으로 삼지 않는다. 기존 구현은 보존한다. 엔진, 최종 런 길이, 모바일 화면 방향은 아직 미정이다.

첫 산출물은 게임 전체가 아니라 **동일한 캐릭터와 배경으로 구성한 초반·성장 후 전투 화면 한 쌍**이다. 별도 일러스트의 화려함보다 실제 플레이 크기에서의 일관성을 판단한다.

## 레퍼런스와 근거 범위

공식 소개와 공식 Steam 페이지의 표시 자료를 참고했다. 전 구간 실플레이 분석이나 성능 비교는 아직 수행하지 않았다. 아래 제작 부담과 적용 판단은 자체 분석이며 각 게임의 개발비에 대한 사실이 아니다.

| 후보 | 레퍼런스 | 가져올 원리 | 제작상 주의 |
| --- | --- | --- | --- |
| A. 어두운 판타지 도트 | Vampire Survivors | 작은 캐릭터의 실루엣, 단순한 전장, 공격과 성장의 시각적 변화 | 모든 자산의 픽셀 크기·윤곽선·색상 수를 맞춰야 한다. 도트라는 이유만으로 제작이 쉬워지지 않는다. |
| B. 단순한 카툰 | Brotato | 굵은 윤곽과 덩어리로 개체 구분, 무기의 식별성 | 단순한 배경·캐릭터도 표정·동작·효과의 완성도가 필요하다. 분위기는 별도로 설계한다. |
| C. 고전 RPG풍 | Halls of Torment | 장비와 캐릭터의 질감, 통일된 복고 판타지 표현 | 작은 크기에서 세부가 뭉개질 수 있다. 캐릭터·적·배경·애니메이션 전체를 맞출 제작 경로가 필요하다. |

Vampire Survivors 공식 소개는 최소한의 조작과 생존·성장을, Brotato는 자동 발사와 웨이브 사이 장비 선택을 설명한다. Halls of Torment는 사전 렌더링된 복고풍 표현을 명시한다. 표현 스타일과 전투 구조는 분리해서 선택할 수 있다. 카툰을 택한다고 상점 웨이브 구조를 가져올 필요는 없다.

**후속 추천 후보: B.** 원작 지향을 우선할 때는 A를 제안했으나, 후속 대화에서 강조한 캐릭터 개성과 움직임 표현에 맞춰 카툰을 먼저 검토한다. 어두운 판타지 분위기와 카툰은 양립할 수 있다. 실제 시안 비교를 먼저 반영하며 세 후보의 미술 자산을 섞지 않는다. 아래 A안 수치는 비교용으로 보존하고 B안 확정 사양으로 전용하지 않는다.

## 공통 시각 우선순위

1. 플레이어 위치와 바로 닿을 위험.
2. 적의 접근 방향과 피할 수 있는 공간.
3. 내 공격의 범위와 처치 반응.
4. 경험치·회복·보상의 위치.
5. 배경 분위기와 장식.

성장 후에도 1~2번을 찾을 수 있어야 한다. 어두운 분위기는 배경 명도와 팔레트로 만들고, 모든 개체를 검게 만드는 방식은 피한다.

## A안의 제작 기준 초안

다음 크기는 레퍼런스 게임의 측정값이 아니라 샘플 제작의 출발점이다.

| 요소 | 제안 기준 | 확인할 것 |
| --- | --- | --- |
| 캐릭터 | 32×32 논리 픽셀 셀에서 시작, 머리·몸통·무기 덩어리 구분 | 실제 표시 크기에서 정지해 있어도 플레이어를 찾을 수 있는가 |
| 일반 적 | 같은 픽셀 단위, 작은 군집형·길쭉한 추격형·넓은 중장갑형 실루엣 | 흑백에서도 종류가 구분되는가 |
| 정예 | 일반 적 대비 약 1.3~1.5배를 시안 비교, 별도 문양·윤곽 추가 | 크기와 색상 외의 식별 단서도 있는가 |
| 배경 | 낮은 대비의 타일, 이동 가능 공간은 반복 장식 절제 | 바닥 장식이 아이템이나 탄환처럼 보이지 않는가 |
| 경험치 | 작은 마름모와 짧은 수집 궤적 | 적 탄환과 모양·운동이 다른가 |
| 회복 | 십자 또는 병 형태, 독립된 아이콘 | 경험치와 즉시 구분되는가 |
| 적 탄환 | 밝은 중심과 외곽, 이동 방향이 보이는 형태 | 내 공격에 겹쳐도 발견되는가 |
| 내 공격 | 무기별 직선·부채꼴·회전 궤도 등 형태 구분 | 색상을 제거해도 무기가 구분되는가 |

도트 자산에는 같은 논리 픽셀 단위와 샘플링 규칙을 적용한다. 카메라 이동·화면 배율에서 픽셀이 흔들리지 않는지 별도 확인한다. 고해상도 그림을 단순 축소한 결과를 완성된 도트 자산으로 간주하지 않는다.

## 성장과 보상의 시각 설계

아래는 게이미피케이션 조사에서 도출할 동기와 연결하기 위한 설계 가설이다.

| 플레이어가 느낄 것 | 화면에서 보여줄 변화 | 피할 것 |
| --- | --- | --- |
| 내가 적을 쓰러뜨렸다 | 짧은 피격 반응 → 사라지는 적 → 남는 경험치 | 적이 멀쩡하다 갑자기 없어지는 반응 |
| 수집하면 성장한다 | 아이템 이동 → 경험치 바 증가 → 레벨업 안내 | 숫자만 증가하고 원인이 보이지 않는 상태 |
| 내가 고른 무기가 강해졌다 | 추가 투사체·범위·공격 방식 중 해당 강화와 일치하는 변화 | 실제 성능과 무관하게 모든 효과만 크게 만들기 |
| 다음 선택이 기대된다 | 업그레이드 카드에 현재 상태와 변경점, 선택 직후 전투에서 확인 | 설명 없는 등급명과 희귀도 연출만 강조 |

피격 80~120ms, 처치 120~200ms, 선택 피드백 100~180ms를 샘플값으로 비교한다. 검증된 정답이 아니다. 지속적인 화면 흔들림·전면 플래시를 기본 효과로 쓰지 않는다. 감소된 모션 설정에서도 상태 변화는 명확해야 한다.

## HUD와 첫 화면 목록

먼저 전투, 레벨업 선택, 일시정지, 결과만 배치한다. 상점·일일 미션·재화 메뉴는 이번 미술 기준에 포함하지 않는다.

- 전투: 상단 경험치 바와 레벨, 상단 중앙 시간, 고정된 체력 위치, 모서리 무기 슬롯과 일시정지. 넓은 안내 카드를 전장 중앙에 상시 배치하지 않는다.
- 레벨업: 무기 아이콘 → 이름 → 지금 달라지는 점 → 선택 버튼 순서. 게임 세계의 테두리·아이콘 규칙을 공유한다.
- 일시정지: 재개를 우선하고 설정·재시작은 구분한다.
- 결과: 생존 시간과 사용한 빌드가 먼저 보이고 재도전으로 이어진다. 상세 통계는 후순위다.
- 본문 한글은 일반 가독성 서체 사용. 도트 장식 글꼴은 짧은 제목에만 검토한다.
- 시안 출발값: 본문 16px, 보조 14px, 터치 영역 48px, 요소 간 간격 8/12/16px. 실제 화면에서 검증한다.
- 버튼 상태: 기본·포커스·눌림·비활성·선택 완료를 구분하고, 선택 완료에는 체크나 문구를 함께 쓴다.

첫 비교 화면은 1280×720 가로로 제작하되 PC 우선 확정은 아니다. 모바일은 844×390 가로와 390×844 세로에서 별도 배치 검토한다. 세로 화면을 가로 화면의 단순 축소로 처리하지 않는다. 조작 방식이 정해지면 엄지 영역·안전 여백·카메라 시야를 함께 결정한다.

## 다음 제작물과 완료 기준

순서대로 한 가지씩 판단한다.

1. **스타일 선택:** A/B/C 중 주된 표현 언어를 선택. 세계관 상세나 엔진은 이 단계에서 고정하지 않는다.
2. **기준 자산 묶음:** 캐릭터 1개, 일반 적 3개, 바닥 타일, 경험치, 무기 아이콘과 공격 효과 각 1개를 같은 화면에 배치. 이름·소재는 독자적으로 만든다.
3. **전투 시안 한 쌍:** 같은 카메라와 배경으로 초반과 성장 후 모습을 비교. 실게임이 아닌 시안임을 표기한다.
4. **화면 검토:** 실제 표시 크기, 흑백, 적·효과 중첩, 모바일 축소에서 플레이어·위험·보상이 구분되는지 확인.
5. **그다음 구현:** 채택한 자산 기준으로 이동·처치·수집의 짧은 플레이를 만든다. 이 시점에 엔진과 자산 제작 경로를 결정한다.

완료 기준:

- [ ] 캐릭터·적·바닥·효과가 같은 픽셀/윤곽/광원 규칙을 따른다.
- [ ] 같은 화면에서 개별 자산을 교체하지 않고 초반·성장 후를 비교했다.
- [ ] 일반 적 3종은 색상 없이도 실루엣이 다르다.
- [ ] 경험치·적 탄환·내 공격의 형태와 움직임이 다르다.
- [ ] 전투 효과가 많아도 플레이어 위치와 탈출 공간을 찾을 수 있다.
- [ ] 선택 카드의 강화 내용이 공격 화면의 변화와 일치한다.
- [ ] 에셋 출처·라이선스·수정 권한을 기록한다. 레퍼런스 게임의 그림은 제작 자산으로 재사용하지 않는다.
