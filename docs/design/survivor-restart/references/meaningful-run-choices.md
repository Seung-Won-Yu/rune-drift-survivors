# 서바이버의 선택과 재플레이 동기

확인: 2026-10-06. 유물·성장·결과 화면을 설계할 때 사용한다.

## 근거와 적용

- Przybylski·Rigby·Ryan의 게임 동기 연구는 전략을 스스로 선택하는 경험과 잘 해냈다는 경험이 즐거움·자발적 재참여와 관련된다고 정리한다. 잿빛의 숲에서는 선택 전 결과를 이해하고, 선택 후 실제 전투 변화가 드러나는 것을 우선한다. 이 연구가 특정 게임의 재방문율이나 이번 구현의 효과를 증명하는 것은 아니다.
- Brotato의 공식 소개는 캐릭터 특성·아이템 조합과 짧은 전투 구간 사이의 성장 선택을 강조한다. 작은 웹 게임에서는 콘텐츠 수를 그대로 따라가기보다, 기존 검·불씨·룬의 다른 전략을 읽을 수 있게 만든다. 이는 우리 게임에 대한 설계 해석이다.
- Slay the Spire 개발자의 GDC 발표는 각 카드가 쓰일 자리가 있도록 반복 조정하고, 수치와 플레이 피드백을 함께 사용하라고 설명한다. 자동 승률만으로 재미나 최선의 유물을 판단하지 않는다.

## 실행 규칙

1. 보상 후보를 알 수 있어야 위험을 감수할 이유를 판단할 수 있다. 알려준 후보는 도전 완료까지 유지한다.
2. 무기가 있어야 적용되는 효과는 현재 무기 보유 여부를 표시한다. 숫자 상승과 다른 움직임/목표를 요구하는 효과를 구분해서 읽게 한다.
3. 회복·반격은 공격 시너지와 다른 선택지다. 후보 모두가 쓸 수 없는 무기 효과가 되는 상황을 피한다.
4. 결과 화면은 다음에 시험할 다른 선택과 실제 발견을 연결한다. 단순 반복 횟수나 새 재화로 플레이 동기를 대신하지 않는다.
5. 알려준 보상을 다시 뽑으려고 미리보기·정지·복귀를 반복해도 후보는 바뀌지 않는다.

## 확인 항목

- 미리 본 후보와 실제 보상 화면의 후보가 같은가?
- 현재 효력이 없는 유물의 조건을 읽을 수 있는가?
- 선택 후 실제 연소·둔화·이동 중 발사·수집 회복 등이 달라지는가?
- 플레이어가 다음 판에 다르게 해볼 선택 하나를 말할 수 있는가?
- 자동 경로가 통과해도 사람의 즐거움은 별도로 확인했는가?

## 출처

- [Slay the Spire: Metrics Driven Design and Balance, GDC 2019](https://media.gdcvault.com/gdc2019/presentations/Giovannetti_Anthony_SlayTheSpire.pdf): 반복 개발과 수치/피드백의 결합.
