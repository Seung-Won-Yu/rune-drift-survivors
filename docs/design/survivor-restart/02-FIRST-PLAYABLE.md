# 잿빛의 숲 — 첫 플레이 버전

2026-09-08 · 사용자가 카툰 비교 시안을 확인하고 기획부터 개발까지 진행을 위임한 뒤 작성.

## 경험 목표

청록 망토의 검사가 숲의 무리에 포위된다. 이동하며 자동으로 검을 휘두르고, 쓰러진 적의 경험치를 모아 새로운 공격을 얻는다. 5분 동안 생존한다. 첫 검의 제한된 범위에서 불씨 투사체와 회전 룬을 더해 넓은 공간을 장악하는 변화가 핵심이다.

이름과 5분 길이는 첫 구현을 위한 제작 결정이며 최종 상품 사양은 아니다. 기존 3D 게임은 비교 자료로 보존하고 새 버전은 `/survivor/`에서 독립 실행한다.

## 기본 규칙

- 이동: WASD/방향키 또는 터치 조이스틱. 공격은 주변 적을 향해 자동 실행.
- 검: 준비 → 타격 → 복귀가 보이는 부채꼴 공격. 강화하면 범위와 피해가 증가.
- 불씨: 적을 향해 날아가는 투사체. 강화를 통해 피해와 발사 수 증가.
- 회전 룬: 캐릭터 주변을 도는 근거리 방어 공격. 강화하면 개수와 범위 증가.
- 경험치: 적 처치 위치에 떨어지며 근처에서 흡수. 레벨업 시 전투를 멈추고 최대 3개 중 하나 선택. 모든 성장을 완료하면 회복 선택 제공. 초반은 빠르게 성장하고 4레벨부터 필요 경험치의 증가 폭을 키워 후반 선택 화면이 너무 자주 열리는 것을 줄인다.
- 보조 성장: 이동 속도, 수집 거리, 최대 체력. 레벨업 선택은 숫자와 플레이상의 효과를 함께 설명.
- 적: 느린 버섯 정령, 빠른 숲 사냥개, 체력이 높은 나무 거인. 시간에 따라 혼합과 밀도 증가. 정예는 크기·표식·체력으로 구분.
- 피격 후 짧은 무적 시간. 중첩 접촉이 한 프레임에 연속 피해를 주지 않음.
- 적 처치와 수집, 레벨업, 피격에 짧은 시청각 피드백. 소리 끄기 지원.
- 사망 또는 5분 생존 시 결과와 재도전. 탭 이탈은 일시정지하며 복귀 후 사용자가 재개.

## 이번 범위와 기술

대표 캐릭터 1명, 적 3종, 무기 3종, 전장 1개, 시작/레벨업/일시정지/결과 화면을 연결한다. 상점·영구 성장·보스 고유 패턴·온라인 기능은 다음 단계의 별도 설계 대상이다.

Canvas 2D 렌더링과 독립된 순수 게임 상태 모듈을 사용한다. 새 의존성 없이 Vite 다중 페이지로 빌드한다. 고정 시간 간격으로 전투를 갱신하고, 렌더링 배율·화면 크기가 공격 규칙에 영향을 주지 않도록 한다. 적/투사체/효과 개수에 상한을 둔다.

이 결정은 Canvas가 모든 목표 성능을 충족한다는 결론이 아니다. 첫 구현에서 적 밀도와 프레임 비용을 측정하고, 목표 콘텐츠가 커지면 렌더러를 재검토한다.

## 미술 기준

캐릭터와 적은 굵은 윤곽선·2단계 음영의 카툰으로 통일한다. 생성된 4포즈 시트는 프로토타입 자산이다. 발 접지와 프레임별 비율은 후속 보완 대상이다. 플레이어는 청록/크림, 경험치는 파랑 마름모, 적 위험은 붉은 표식, 무기 효과는 황금/청록으로 구분한다. 바닥은 저대비의 흙·풀·돌 패턴으로 구성한다.

HUD는 체력·경험치·시간·현재 무기에 집중한다. 캐릭터 가까이에 상시 설명 카드를 두지 않는다. 모바일은 조이스틱 영역과 레벨업 카드의 접근성을 먼저 확보한다.

## 완료 확인

- 시작 → 이동과 처치 → 경험치 → 강화 → 사망/생존 → 재도전이 연결된다.
- 선택한 무기가 전장에 나타나고 실제 피해를 준다.
- 일시정지/레벨업/탭 이탈 중 시간이 흐르지 않는다.
- 빠른 입력·터치 취소·키 해제 후 이동이 남지 않는다.
- 390px 세로와 데스크톱에서 버튼·체력·업그레이드가 화면 밖으로 나가지 않는다.
- 시드 기반 시뮬레이션으로 성장·피격·승리·재시작을 검증한다.
- GitHub Pages의 하위 경로에서도 새 페이지와 자산이 로드된다.

## 다음 판단

사용자가 첫 전투에서 느끼는 속도, 캐릭터 크기, 공격의 시원함을 바탕으로 조정한다. 이후 첫 무기 진화와 정예/보스의 구별되는 패턴을 추가한다. 콘텐츠 수량보다 같은 무기의 초반과 성장 후 차이를 우선한다.
