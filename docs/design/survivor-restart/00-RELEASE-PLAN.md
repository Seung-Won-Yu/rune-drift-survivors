# 잿빛의 숲 — 완성까지의 개발 기준

2026-09-08 · 사용자의 ‘끝까지 개발 진행’ 위임을 받았다. 아래는 구현 순서와 검증 항목이며 현재 기능만으로 완료를 선언하지 않는다. 기존 문서 01~04는 각 시점의 시안/첫 플레이 기록이다.

## 지향점

브라우저에서 바로 시작하고, 캐릭터를 고르고, 성장하는 공격으로 무리를 돌파하고, 마지막 보스까지 도전한 뒤 다른 빌드로 다시 하고 싶은 2D 카툰 서바이버. 캐릭터와 공격의 실제 움직임, 위험 식별, 성장 선택을 우선한다. 기존 3D 게임은 보존한다.
