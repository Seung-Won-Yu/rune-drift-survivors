# 잿빛의 숲 — 완성까지의 개발 기준

2026-09-08 · 사용자의 ‘끝까지 개발 진행’ 위임을 받았다. 아래는 구현 순서와 검증 항목이며 현재 기능만으로 완료를 선언하지 않는다. 기존 문서 01~04는 각 시점의 시안/첫 플레이 기록이다.

## 지향점

브라우저에서 바로 시작하고, 캐릭터를 고르고, 성장하는 공격으로 무리를 돌파하고, 마지막 보스까지 도전한 뒤 다른 빌드로 다시 하고 싶은 2D 카툰 서바이버. 캐릭터와 공격의 실제 움직임, 위험 식별, 성장 선택을 우선한다. 기존 3D 게임은 보존한다.

첫 챕터의 기능·그림·입력·기록·전체 플레이와 로컬 출시 검증을 마쳤다. main 기능 커밋·푸시를 마쳤으며 남은 게이트는 실제 Pages 배포 확인이다. 상점/온라인 기능은 재미를 만들기 위한 필수 수단으로 고정하지 않는다. 실제 플레이를 바탕으로 더 간단하고 분명한 성장/해금 구조를 선택한다.

전체 완료 전에는 항목마다 현재 파일, 실행 결과, 화면, Git/배포 상태를 다시 대조한다. 테스트 개수나 빌드 성공만으로 게임 전체의 완성을 대신하지 않는다.
