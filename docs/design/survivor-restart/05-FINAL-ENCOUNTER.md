# 최후의 대결 — 재의 군주

2026-09-08 · 전체 개발 목표 진행 중. 이번 기록은 보스 단계의 구현과 검증이며 게임 전체의 완성을 뜻하지 않는다.

## 한 판의 결말

4분에 재의 군주가 한 번 등장한다. 일반 적 상한이 가득 찼더라도 보스 자리를 확보한다. 등장 후 일반 적 생성은 1.6초당 1마리로 줄고 추가 정예 생성은 멈춘다. 등장 1.4초 동안은 공격 준비 상태로 피해를 받지 않는다.

- 보스 체력 3,200, 플레이어와 적의 실제 무기 피해 규칙을 공유한다.
- 보스를 처치하면 즉시 승리한다. 제한 시간 5분까지 보스가 남아 있으면 ‘살아 돌아왔습니다’ 생존 결과를 표시한다. 사망은 별도 패배 결과다.
- 보스 체력바, 현재 공격 안내, 화면 밖 방향 표식을 제공한다. 가로로 짧은 화면에서는 체력바를 하단에 두어 캐릭터를 가리지 않게 한다.

## 공격

| 공격 | 예고 | 실행 | 회피/빈틈 |
| --- | --- | --- | --- |
| 돌진 | 시작 지점과 방향을 고정한 1초 예고, 폭 64·거리 270의 경로와 화살표 | 0.65초 동안 예고한 방향으로 이동, 28 피해 | 경로 옆으로 이동. 종료 후 0.8초 회복 동작 |
| 가시 탄막 | 1초 동안 발사 방향을 보여주는 방사선 | 7발, 속도 150, 16 피해, 3.8초 뒤 소멸 | 움직이는 화살촉 사이의 틈으로 이동. 발사 후 0.8초 회복 동작 |

두 패턴을 번갈아 사용한다. 체력이 절반 이하가 되면 재사용 대기가 2.6초에서 1.82초로 줄고 가시가 11발로 늘어난다. 탄환 상한은 96개다. 피격 무적 시간을 공유하므로 같은 순간 여러 탄환이 체력을 중첩해서 깎지 않는다. 일시정지/강화 선택 중 보스 준비 시간과 탄환이 함께 멈춘다.

## 미술과 화면

일반 나무 거인과 구별되는 뿔 왕관, 상아색 가면, 자주색 잎 망토의 보스 시트를 제작했다. 이동 4포즈와 공격 4포즈를 상태에 연결한다. 첫 출력의 체크무늬 배경은 사용하지 않았고, 이미지 생성 도구로 배경을 제거한 RGBA 버전을 최종 채택했다.

최종 자산: `public/art/survivor/ash-sovereign.png`.
출처·생성·편집 프롬프트: [ASH-SOVEREIGN-PROMPT.md](../../../public/art/survivor/ASH-SOVEREIGN-PROMPT.md).

적 탄환은 플레이어의 효과 위에 그리는 붉은 화살촉이다. 경험치 마름모와 내 불씨/검기와 모양·방향이 다르다. 돌진 경로와 실제 공격은 같은 상수를 사용한다.

## 확인 결과

- 순수 상태 검사 20개, 브라우저 검사 14개 통과.
- 보스 상한/중복 등장, 등장 보호, 예고 방향 고정, 회피/피해, 공격 간 대기, 탄환 수명, 강화 중 정지, 실제 피해를 통한 승리, 생존/패배 구분, 재시작을 검증했다.
- 1280×720, 390×844, 740×360에서 보스 HUD와 두 공격을 캡처하고 검토했다. 짧은 가로 화면의 HUD 가림을 수정하고 관련 3개 장면 재검사도 통과했다.
- 기본 빌드 통과. 새 자산을 포함한 하위 경로 배포 빌드 확인은 최종 전달 단계에서 다시 수행한다.
