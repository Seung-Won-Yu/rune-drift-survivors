# 동료 중심 출발 화면과 전투 잉크

2026-10-07. 사용자의 “디자인도 최선인가?” 후속 요청에 따라, 앞선 게임 규칙 확장과 구분하여 실제 화면의 완성도를 높인다. 숲·황동·종이 도감·2D 카툰 방향과 한 화면/내부 스크롤 제약을 유지한다.

## 변경

- 세 동료의 로비용 전신 일러스트를 새로 제작했다. 기존 의상과 정체성을 유지하며 숲 배경과 어울리는 붓 질감, 재질, 표정, 따뜻한 가장자리 빛을 더했다. 캐릭터 선택 때만 짧게 등장하며 모션 감소에서는 정적이다.
- 동료 선택을 숲 무대로 옮겼다. 선택한 동료와 세 선택 버튼이 같은 영역에 있고, 오른쪽 장부는 실제 출발 준비에 집중한다. 동료 선택, 도감, 준비/기록 이동, 출발은 기존 동작을 유지한다.
- 고유 능력은 이름·행동 요약을 먼저 보여 주고 상세 수치는 ‘동료의 전투 방식’에 남긴다. 전승의 자유 출발은 한 줄, 두 갈래는 그림과 효과로 비교한다. 잠긴 항목의 중복 문구를 줄이고 기록을 모아 열리는 형태는 유지한다.
- 준비 본문은 12–13px, 주요 선택 이름은 13–17px로 조정했다. 작은 화면의 동료 버튼에도 이름·선택/해금 진행이 남는다. 세로 공간이 매우 작을 때는 큰 그림을 접어 선택 버튼과 출발을 우선한다.
- 전투에는 이동에 맞춘 작은 흙먼지, 실제 피격에 맞춘 절단선, 방향을 읽을 수 있는 베기 리본, 세 챔피언의 문장을 추가했다. 효과는 시뮬레이션 시간만 읽고 게임 상태·난수·충돌·피해를 바꾸지 않는다. 적의 위험 예고는 마지막에 그려져 항상 위에 남는다.
- 가시 송곳니의 자세 변화는 일반 사냥개 시간이 아닌 실제 챔피언 돌진 시간에 맞췄다.

새 로비 그림은 합계 618,602바이트이며 한 번에 선택된 그림만 요청한다. 기존 전투 아틀라스를 교체하거나 프레임 수를 늘린 변경은 아니다. [원본 프롬프트·자산·알파 검증](../../../public/art/survivor/PORTRAIT-PROMPTS.md).

## 완료 기준과 근거

| 요구 | 검증 방법 | 상태 |
| --- | --- | --- |
| 세 동료의 일러스트와 선택이 일치 | 브라우저에서 세 동료 선택·실제 이미지 크기/로드·선택 상태 검사 | 로컬 통과 |
| PC·모바일·짧은 가로 화면에서 선택과 출발 유지 | 1280×720/600, 390×844, 320×568, 640×360, 740×360 레이아웃·키보드·내부 스크롤 검사 | 로컬 통과 |
| 실제 화면의 가독성과 정체성 | IAB 렌더 검토, 데스크톱/모바일/가로 캡처 | 로컬 통과 |
| 전투 상태 불변·위험 예고 우선 | 기존 렌더 상태 불변/예고 픽셀 검사, 챔피언 자세 시점 검사, 모션 감소 검사 | 로컬 통과 |
| 저장·수집·출발·재시도 회귀 없음 | 전체 survivor 단위/브라우저 테스트 | 로컬 통과 |
| Pages 경로·자산·공개 실행 | Pages 빌드·production smoke·배포 후 공개 화면 | 로컬 빌드 경로 통과, 배포 확인 대기 |

첫 시각 검토에서 본문 색과 HUD 초상 크기 규칙이 CSS 정리 중 빠진 것을 발견해 복구했다. 640×360은 미디어 쿼리 충돌 가능성이 제기되어 실제 렌더를 확인했다. 해당 화면에서는 부모가 grid여서 flex-basis가 적용되지 않으며 선택 버튼은 모두 표시된다. 이 경계값도 자동 검사에 추가했다.

사용자 기기에서의 취향·장기 플레이 만족도·저사양 물리 기기 성능은 이번 자동 검사로 증명하지 않는다. 전투용 캐릭터의 네 포즈 및 좌우 반전 제약도 그대로다.


## 로컬 검증 결과

- 단위 검사 137개 통과. 기존 브라우저 검사 121개 통과 후 등장 모션과 이름 영역의 순간 겹침 3건을 수정했다. 새 이미지 검사의 잘못된 예상 문구 1건도 실제 능력 설명에 맞게 바로잡았다. 실패했던 범위를 포함한 7개 검사(6개 화면 크기 + 세 이미지/선택/모션 감소)는 재실행 통과했다.
- Firefox 관련 검사 15개 통과. WebKit은 14개 통과 후 640px 가로 화면에서 영역 끝의 소수 픽셀 잘림을 검출했다. 무대에 2px 내부 여백을 두었고 6개 화면 레이아웃 재검사 전부 통과했다. 기존 버튼 크기·전체 표시 단언은 완화하지 않았다.
- 밀집 전투 12초 × 3화면 검사에서 p95 16.7–16.8ms, 50ms 초과 프레임 0. 이는 해당 데스크톱 자동 브라우저 실행 결과이며 물리 휴대폰 성능 수치가 아니다.
- Pages 빌드와 production smoke 통과: 새 Ash 일러스트 포함 자산 로드, 공개용 빌드의 QA API 제거, 도감 22항목, 출발·일시정지, 폰트 확인.
- IAB에서 1280×800, 390×844, 640×360 화면과 실제 초반 검 전투를 확인했다. [데스크톱](./images/illustrated-camp-1280.png), [모바일](./images/illustrated-camp-390.png) 캡처는 세 동료와 두 발견을 가진 격리된 QA 프로필이며 사용자 저장 데이터가 아니다.
